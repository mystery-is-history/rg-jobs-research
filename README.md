🌐 RG JOBS RESEARCH

Your Remote Work & Work-From-Home Job Research Dashboard

RG JOBS RESEARCH is a simple, user-friendly dashboard designed to help people discover remote job platforms, work-from-home opportunities, and freelancing websites in one place.

🚀 Live Demo

"Open RG JOBS RESEARCH" (https://YOUR-USERNAME.github.io/rg-jobs-research/)

Replace "YOUR-USERNAME" with your GitHub username.

✨ Features

- 🔎 Search for job platforms.
- 🗂️ Browse platforms by category.
- ⭐ Save your favourite platforms.
- ➕ Add custom platforms.
- 📱 Responsive and mobile-friendly interface.
- 🌐 Direct links to job websites.
- 💾 Saves bookmarked and custom entries locally in your browser.

🌍 How to Use

1. Open the live dashboard.
2. Search for a job platform.
3. Select a category to explore platforms.
4. Save platforms you want to revisit.
5. Open the official website using its link.

🚀 Deployment

This project is hosted using GitHub Pages.

To deploy your own copy:

1. Fork or create this repository.
2. Upload "index.html".
3. Open Settings → Pages.
4. Select the "main" branch and "/ (root)".
5. Save and wait for deployment.

⚠️ Important Safety Note

- Always check a company's legitimacy before applying.
- Never pay registration fees to suspicious recruiters.
- Never share OTPs, passwords, or banking credentials.
- Check age and eligibility requirements before applying.
- Job availability and platform policies may change.
